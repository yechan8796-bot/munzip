# 학급문집 만들기

아이들 글 스캔본으로 학급문집을 만드는 웹앱이에요. 간지 인쇄부터 스캔 안내, 여백 자르기와 편집, 표지 협동화까지 한 화면에서 해요.

모든 파일은 브라우저 안에서만 처리되고 어디에도 전송되지 않아요. 설치도, 회원가입도 필요 없어요.

## 단계

1. **간지 만들기** — 주제별 제목을 적으면 검은 바탕에 큰 흰 글씨로 간지 PDF를 만들어요. 스캔할 때 글 묶음 사이에 끼우면 3단계에서 주제별로 자동으로 나뉘어요.
2. **글쓰기와 스캔** — 글양식(한글 파일)을 내려받고, 복합기 스캔 설정을 확인해요. (400×400dpi, 그레이스케일, PDF 비압축, 파일 이름에 01_, 02_ 번호)
3. **문집 엮기** — 스캔본 여백을 자동으로 자르고, 순서·속표지·중간표지를 정리해서 한글(hwpx) 파일이나 PDF로 만들어요.
4. **표지 협동화** — 표지 그림을 A4 조각으로 나눠 인쇄하고, 색칠한 조각을 스캔해 다시 한 장으로 합쳐요. 표지 양식(PPT·키노트·글꼴)도 내려받을 수 있어요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 학급문집 만들기 앱 (글양식, 표지 양식, 글꼴, 안내 그림이 모두 들어 있는 파일 하나) |
| `hyeop.html` | 협동화 조각 메이커 (따로 열어 쓰는 버전) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내게 하는 빈 파일 |

## 알아 둘 것

- 작업은 쓰는 브라우저에 자동 저장돼요. 다른 컴퓨터로는 옮겨 가지 않아요. 학교 PC 복원 프로그램이나 시크릿 창에서는 저장이 사라지니, 3단계의 "작업 파일로 저장"으로 백업해 두세요.
- 메모리를 많이 써요. 350장 정도는 메모리 8GB 이상 컴퓨터를 권해요.
- 크롬이나 엣지 최신 버전에서 쓰세요.
